Phase Kickback

Phase kickback is an interesting interaction involving a control gate. Normally, the control gate changes the target qubit only. But with phase kickback, the phase of the control qubit can be changed.

  1. Reset the Workspace

    Clear the circuit using the Clear button in the upper right.

  2. Put qubit 4 into superposition.

    Apply an H gate to qubit 4. Remember qubit 4 is the last qubit and is the LSB of the state vector.

    • States |00000> and |00001> should "light up" in the phase disks, and have probabilities of 50% in the probabilties table.
  3. Put qubit 3 into the |-> state.

    First apply an X gate to qubit 3 followed by an H gate.

    • Notice that the states |00010> and |00011> are now lit up, and there are now 4 non-zero states, each with a probability of 25%.
    • The phase of the states |00010> and |00011> are "negative". Note on the phase disks that they are red and now pointing to the left, 180° rotated.
    • Remember, for the phase to be changed, the target qubit of the gate must be a 1 in a state vector for that state vectors phase to change (and it has to have a non-zero amplitude).
  4. Conditionally flip qubit 3 based on qubit 0

    Apply a CNOT to qubit 3 with qubit 4 as the control.

    • The two states that have qubit 4 (control) as 1 are |00001> and |00011>.
    • The CNOT gate flips qubit 3 if qubit 4 is a 1.
    • Notice that states |00001> and |00011> phase have changed. The states where qubit 4 was a 1.
    • The phase has been kicked back to states where qubit 3 was a 1.
    • Remember, phase is additive. |00011> had a phase of 180°, then another 180° was kicked back onto it rotating it back to 0°.
    • Try using the "Back" and "Forward" buttons to move back and forth watching the phase disks.

Final Notes

  • Phase kickback is a foundational operation used by many quantum algorithms.
  • It reverses the "cause and effect" between the control and target qubits.
  • The control qubit must be in superposition.
  • It can be used to read information from a quantum state without changing it.
