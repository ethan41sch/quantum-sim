Quantum Fourier Transform

  1. Reset the Workspace

    Clear the circuit using the Clear button in the upper right.

  2. Initialize qubits to a binary value using X gates.

    Using X gates, flip qubits to a 1 in order to encode a binary value. This works best if the encoded value is a factor of 32 (the size of our state vector space).

  3. Apply Quantum Fourier Transform

    Use the QFT pre-built operator to apply the quantum fourier transform.

    • The value originally encoded was the frequency. If this value is 'n', then the QFT causes the phases of the state vectors to be rotations so that 'n' full rotations occur across the 32 states.
    • Use the phase disks to visually identify where the phase pattern repeats. For example, if the original encoded value was 4, then the phase repeats on each row. If 2 was the encoded value, then it takes two rows of phase disks to complete a full rotation.
    • The number of times this rotation completes is the frequency.

Final Notes

The Quantum Fourier Transform is usually used for state preparation or transformation. Here are some use cases:

  • To create a periodic phase pattern across the states.
  • To perform Quantum Arithmetic.
  • To solve differential equations.

In general, the inverse Quantum Transform is used by more algorithms, but the QFT is still useful.
