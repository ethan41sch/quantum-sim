Grover Diffusion Operator

This guide walks through the Grover Diffusion operator. This is the main component of Grover's Algorithm. In Grover's algorithm, this operator will be applied repeatedly to arrive at the answer. The number of times it needs to be applied is sqrt(N) where N is the size of the search space.

  1. Reset the Workspace

    Clear the circuit using the Clear button in the upper right.

  2. Initialize Superposition

    Apply the Superposition State pre-built operator to apply an H gate to all qubits.

    • Probabilities (table at lower left) for all 32 states are now ~3.1% (1/32).
    • Phase disks show a phase angle of 0° (pointing right).
    • In 3D Waves view: White lines are in sync, indicating uniform phase.
  3. Phase flip state |11111>

    Apply an MCZ gate to qubit 4.

    • The MCZ gate is a multi-control Z gate.
    • It applise the Z gate to a state if all of the control qubits are 1 in that state.
    • In our setup, this will flip the phase of state |11111>.
    • In the phase disk view, the phase disk for |11111> should now have a red dial and point to the left (180°).
    • In the History view, the amplitude for |11111> should be red and inverted (below the axis).
    • This is how the system state should be in preparation for the Grover Diffusion operator.
    • The state which has a negative amplitude (negative phase), is the state which is the "correct" answer.
    • Notice that the probabilities for all of the states are still 3.1% (1/32). All that has been changed is the sign of the amplitude, not the magnitude.
  4. Apply Grover's Diffusion Operator

    Use the pre-built operator to apply a Grover Diffusion.

    • Scroll down to the state |11111> in the probabilities table. It should now be around 25%. The other state probabilities have been reduced to about 2.4%.
    • In the history view, the magnitude of the amplitude of |11111> is also visibility larger than the other states.
  5. Optional: Repeat the process.

    Grover's Algorithm repeats this process sqrt(N) times. Each iteration will increase the amplitude of the "correct" answer. This can be done here, but take note:

    • Notice in the phase disk view, all of the phases are the same.
    • It doesn't matter what the phases are, just that they are the same.
    • For the Grover Diffusion operator, the "correct" answer must have the opposite phase from the "incorrect" answers.
    • Therefore, to repeat the process, first apply an MCZ gate to qubit 4, then apply the Grover Diffusion operator.
    • For a state space size of 32, repeating it 5 times will maximize the probability for |11111>.

  6. Instructions on what button to press or gate to move.

    • What the user should notice in the Phase Disks.
    • What the user should notice in the 3D Waves.

Final Notes

  • In this recipe, we targeted the state |11111> as the "correct" answer. This was to simplify the recipe.
  • In a real use of Grover's algorithm, there would be an "oracle" quantum circuit. The oracle would evaluate all of the states and emit a 1 bit for the state that is correct and 0 bits for all of the incorrect states. This bit would then be used do perform a multi-target CZ operation on the states.
  • For example, the oracle could be a circuit that evaluates a boolean expression for 3SAT. The input to the circuit is the superposition of all possible states, one qubit for each variable in the expression. Only the "correct" answer will emit "True" (a 1 bit).
  • In general, if one has "f(x) = y", and 'y' is known, Grover's algorithm can find 'x'. A quantum circuit can be built that evaluates f(x) and then compares the result to 'y', emitting a 1 bit if equal.
