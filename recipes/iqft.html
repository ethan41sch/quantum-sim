Inverse Quantum Fourier Transform

Follow these steps to set up a circuit and analyze frequency and periodicity using the Inverse QFT.

  1. Reset the Workspace

    Clear the circuit using the Clear button in the upper right.

  2. Initialize Superposition

    Apply the Superposition State pre-built operator to apply an H gate to all qubits.

    • Probabilities (table at lower left) for all 32 states are now ~3.1% (1/32).
    • Phase disks show a phase angle of 0° (pointing right).
    • In 3D Waves view: White lines are in sync, indicating uniform phase.
  3. Apply Phase to Qubit 4

    Apply a T gate to qubit 4 (bottom row).

    • As qubit 4 is the LSB, every other state now has a phase angle of 45°.
    • 3D Waves view: Phase lines alternate between two different angles.
  4. Apply Phase to Qubit 3

    Apply an S gate to qubit 3 (next to last row).

    • Phases are additive: you will see 0°, 45°, 90°, and 135°.
    • Phases only shift if the gate's qubit is |1⟩.
  5. Apply Phase to Qubit 2

    Apply a Z gate to qubit 2.

    • One can now see a period of 8 and a frequency of 4.
    • In 3D Waves: The composite wave is zeroed out due to complete destructive interference.
    • Probabilities remain 3.1% because phase gates do not affect amplitude.
  6. Run the Inverse QFT

    Use the invQFT button to apply the transform.

    • Result: A single state |00100> (value 4) has 100% probability.
    • Calculation: 32 (state space) / 4 (frequency) = 8 (period).

Final Notes

  • If the frequency isn't a clean divisor of the state space, the Inverse QFT provides the closest approximate answers.
  • This mechanism is the core of Shor's Algorithm for integer factoring.
